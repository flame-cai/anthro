## Overview

`anthro` is an independent implementation of the WHO Child Growth Standards methodology for Python and JavaScript.

This repository contains both:

1. Original source code and documentation authored for this project; and
2. Reference data and other material derived from or associated with external sources, including WHO Child Growth Standards resources.

These categories are treated separately for licensing purposes.
